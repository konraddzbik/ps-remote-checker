How to test from away

  1. Connect a laptop to the Wi-Fi the PS Portal will use, or to your phone hotspot. Turn Tailscale off on it, or the test won't use the real internet path.
  2. Mac app: open 2 · Away (PS Portal), enter the code, click Run.
  3. Terminal: python3 -m ps_remote_checker remote --pair …
  4. The result appears in the table above.

Security

  1. This panel is only served through Home Assistant Ingress (your HA login / Tailscale).
  2. No ports are forwarded. The helper opens a UDP path only for a test, only with a matching code, and only for about 30 s.
  3. The relay sees encrypted messages only. The code never leaves your devices.
  4. Rotate the code with New code if you shared it.
